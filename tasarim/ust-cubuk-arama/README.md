# Üst çubuktaki Ctrl+K arama kutusu kaldırıldı (M11, 20.11.2026)

Üst çubuktaki "Ara veya komut çalıştır" kutusu makale, belge ve PDF
aramalarıyla karışıyordu. Kutu kaldırıldı; komut paletinin kendisi ve
Ctrl+K / ⌘K kısayolu olduğu gibi duruyor.

Palete erişim:

- **Klavye:** Ctrl+K (her ekranda, editörün içinde de).
- **Hesap menüsü:** "Komut paleti" girişi (masaüstünde kenar çubuğunun
  altındaki, tablet/telefonda üst çubuktaki menü). Tıklanınca menü kapanır.
- **Telefon:** alt çubuktaki "Daha fazla" / "Çalışma" penceresinin altında
  "Komut paleti" girişi. Dokunmatik ekranda kısayol rozeti gizli.

Makale Bul, belge içi Bul-Değiştir ve PDF araması kendi yerlerinde,
dokunulmadı.

Kabul: `node tasarim/ust-cubuk-arama/betikler/kabul.mjs` (yerel yığın +
`next start -p 3150`), sonuç `kabul-sonucu.json` (11/11).
