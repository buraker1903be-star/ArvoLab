# Geri alma dosyaları

`supabase/migrations/` içindeki bir migration'ı geri almak gerekirse çalıştırılacak SQL. Supabase CLI bu klasörü
uygulamaz; elle, bilerek çalıştırılır. Her dosya hangi migration'ın karşılığı olduğunu, neyin kaybolacağını ve
uygulama kodunun hangi sırayla geri alınması gerektiğini yazar.

Dosya adı geri aldığı migration'ın adıyla aynıdır.
